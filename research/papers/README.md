# Paper PDFs

Drop retrieved paper PDFs here as `<arxiv-id>.pdf` (e.g. `2404.17562.pdf`), or
`<first-author><year>.pdf` when there's no arXiv id (paywalled finals).

PDFs are **gitignored** (copyright + size); only this README and the bibliography in
`../../RESEARCH-INDEX.md` § 3 are committed. When you add a PDF, update its row in the
bibliography (status → `retrieved`, fill the arXiv id / DOI).
