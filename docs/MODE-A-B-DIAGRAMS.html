Tessera — Mode A & Mode B

How the two-mode observation architecture functions today

Tessera runs one detector substrate in two modes, chosen per‑emitter by a validity_class gate. Mode A is the always‑on layer — it ranks shards by evidence and abstains when it cannot make a calibrated claim, with no false‑discovery‑rate promise. Mode B is a narrow, revocable upgrade that earns an FDR ≤ q guarantee by building a valid spatial null from a concurrent control twin (d = treatment − control), which cancels the common‑mode the temporal null cannot on nonstationary GPU telemetry.

Mode A is honest about uncertainty: it surfaces and ranks, and when it cannot make a calibrated claim it abstains instead of guessing. gpu_temp_c at 1 Hz is the canonical abstainer — near‑unit‑root physics (φ≈0.992) means there is no valid temporal null, so it stays in Mode A permanently. That abstention is intrinsic and correct, not a fixable artifact (confirmed against a genuine 2‑month 1 Hz baseline).

3Mode B  FDR guarantee via a spatial null

A guarantee needs a valid null. On drifting telemetry, build it in space, not time.

The contrast d = t − c is the whole trick. Treatment and its twin feel the same workload, ambient temperature and power regime at the same instant, so subtracting them cancels the common‑mode exactly — leaving a clean null the drifting temporal baseline could never give. Fit on a healthy window (center → whiten → standardize), apply to the monitoring window, turn each shard into one e‑value, and run e‑BH for FDR ≤ q.

4Why spatial, not temporal — the data

Same detector, same q = 0.1. Only the null construction changes.

xychart-beta
  title "False-discovery proportion by null construction  (lower is better; target q = 0.1)"
  x-axis ["Temporal", "Single twin (bad ctrl)", "Spatial twin", "Control triad"]
  y-axis "FDP" 0 --> 1
  bar [0.97, 0.58, 0.003, 0.0]

FDP at 1 Hz scale. Temporal over‑selects catastrophically; a single twin fails when the control itself is contaminated; the matched spatial twin and the control triad sit at or below target.

Temporal compares a shard against its own past — drift contaminates it → FDP ≈ 0.97. Spatial compares a shard against its twin at the same instant — common‑mode cancels → FDP ≈ 0. The single twin has one weakness (a contaminated control makes t−c false‑fire, FDP ≈ 0.58); the triad (§7) closes it.

An emitter rides into Mode B when its construction holds, dispatches FDR‑controlled actions, and falls back to Mode A — dropping all its actions — the instant the monitor or whiteness check says its null is no longer trustworthy. An action keyed to a bounded error rate must never outlive the guarantee it was keyed to.

7The control triad (ADR 0022) — hardening the spatial null

A second twin lets the construction self‑check when a control goes bad.

A single twin has one blind spot: if the control is contaminated, t − c fires even though the treatment is healthy (a sign‑blind false positive, FDP ≈ 0.58). The triad adds a second twin so c1 − c2 becomes a clean control‑vs‑control reference that flags the bad control, and detection routes to the clean sibling t − c2 → FDP back to 0.000 at recall 1.000. Note: applyTriadRouting is in‑memory only today; wiring it into the streaming / 1 Hz‑at‑scale path is the top remaining item.
